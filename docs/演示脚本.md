# 知更 AI · 演示脚本

## 一、2 分钟演示视频（12/4 提交）

> 建议录屏 1920×1080，真实数据模式（启动后端 + 前端），配简短字幕。片头标注「信息以来源官网原文为准」。

| 时间 | 画面 | 旁白要点 |
| --- | --- | --- |
| 0–20s | 几个校园网站通知页面快速切换 | 痛点：竞赛、实践、讲座信息散落多个网站，截止日期藏在长文里 |
| 20–35s | 首页今日简报：「有几件事快截止了」→ 三个统计卡 → 「优先处理」卡片直接显示倒计时、下一步报名方式、参与对象 | 不再让人自己翻 64 条：AI 把关键信息整理成「今天该做什么」；点数字下钻 |
| 35–45s | 从简报点进「全部通知」→ 搜索「竞赛」→ 切「7 天内截止」 | 想深挖时仍有完整检索：搜索、筛选、排序、URL 可分享 |
| 45–80s | 打开一条真实竞赛通知详情：AI 字段（截止/对象/报名方式）→ 原文依据「在正文中定位」高亮 | AI 提取关键信息但**不编造**：每个字段附原文证据；没依据的标「待核实」 |
| 80–105s | 收藏一条 → 我的收藏（按截止排序）→ 手机视口展示首页 | 收藏追踪、7 天内截止高亮；手机电脑都能用 |
| 105–120s | 关于页 / 架构图一闪而过 | 采集 → AI 解析 → 证据校验 → 展示；83 个自动化测试保障质量 |

**备用镜头**（时间富余时）：手动触发 `POST /api/v1/admin/sync` 展示一次真实同步（证明后端在跑）。
**答辩常备答案**：数据真实性（证据回文校验 + 原文链接）、AI 误判怎么办（待核实 + 原文对照）、和教务系统/公众号区别（公开信息聚合、无需登录、留证据链）。

## 二、30 秒中期检查录屏（如需录屏替代截图，11/28 前）

1. (0–5s) 首页今日简报：统计数字 + 「优先处理」行动卡（展示 AI 直接给结论）
2. (5–10s) 点统计卡进入全部通知列表 + 筛选一次
3. (10–20s) 点开一条通知详情：AI 提取结果 + 原文依据
3. (20–30s) 收藏一条 → 我的收藏，口播「以上为真实采集数据，详情可核对原文」
