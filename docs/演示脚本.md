# 知更 AI · 演示脚本

## 一、2 分钟演示视频（12/4 提交）

> 建议录屏 1920×1080，真实数据模式（启动后端 + 前端），配简短字幕。片头标注「信息以来源官网原文为准」。

| 时间 | 画面 | 旁白要点 |
| --- | --- | --- |
| 0–20s | 几个校园网站通知页面快速切换 | 痛点：竞赛、实践、讲座信息散落多个网站，截止日期藏在长文里 |
| 15–30s | 分组首页：三组 14 类 → 点「选择重点关注类别」勾选几类并保存，首页只剩关心的部分 | 信息再多也能按自己关注的范围收敛；教务处与学院官网内容统一归类 |
| 30–40s | 公示类简报：倒计时「公示期至」、异议反馈、公示对象、发布单位；再切到竞赛类看级别/团队规模 | 同类信息按同一套字段整理，不用逐条点进详情找 |
| 40–50s | 信息源页：关键词搜索「成都大学 教务处」→ 选中候选 → 显示探测结果与样例标题 → 确认添加 | 信息源可以自己扩；不只预置 4 个网站 |
| 50–60s | 从分类简报点进「全部通知」→ 搜索「竞赛」→ 切「7 天内截止」 | 想深挖时仍有完整检索：搜索、筛选、排序、URL 可分享 |
| 60–85s | 打开一条真实竞赛通知详情：AI 字段（截止/对象/报名方式/分类专属字段）→ 原文依据「在正文中定位」高亮 | AI 提取关键信息但**不编造**：每个字段附原文证据；没依据的标「待核实」 |
| 85–108s | 收藏一条 → 我的收藏（按截止排序）→ 手机视口展示分类首页 | 收藏追踪、7 天内截止高亮；手机电脑都能用 |
| 108–120s | 关于页 / 架构图一闪而过 | 采集 → AI 解析 → 证据校验 → 展示；105 个自动化测试保障质量 |

**备用镜头**（时间富余时）：手动触发 `POST /api/v1/admin/sync` 展示一次真实同步（证明后端在跑）。
**答辩常备答案**：数据真实性（证据回文校验 + 原文链接）、AI 误判怎么办（待核实 + 原文对照）、和教务系统/公众号区别（公开信息聚合、无需登录、留证据链）。

## 二、30 秒中期检查录屏（如需录屏替代截图，11/28 前）

1. (0–5s) 分组首页：三组 14 类，演示勾选重点关注类别后首页收敛
2. (5–10s) 分类简报：倒计时 + 该类专属字段；再点进全部通知筛选一次
3. (10–20s) 点开一条通知详情：AI 提取结果 + 原文依据
3. (20–30s) 收藏一条 → 我的收藏，口播「以上为真实采集数据，详情可核对原文」
