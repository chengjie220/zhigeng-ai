## 一、AI 在开发中的角色（如实披露）

| 阶段 | AI 参与内容 | 人工把关 |
| --- | --- | --- |
| 产品设计 | 生成 10 天开发设计方案（功能取舍、架构、接口契约、测试与风险预案） | 团队讨论取舍，确认双人分工与范围 |
| 前端开发 | 生成 Vue3 工程骨架、五个页面、组件、Mock 数据、工具函数 | 逐文件审查；v0.2 交互增强与缺陷修复后合入 |
| 后端开发 | 生成采集适配器、AI 解析模块（LLM+规则降级）、API、同步任务 | 按真实站点实测结构校准解析器；两轮质量修正 |
| 测试 | 生成单元/集成测试与真实 HTML 夹具用例 | 全部用例本地执行通过后入库（前端 61 + 后端 22） |
| 文档 | 生成 README、测试记录、中期材料、作品说明底稿 | 人工核对数据与提交号，确保陈述与仓库一致 |

## 二、AI 产出的可验证性

- 所有代码经 `npm run test` / `npm run build` / `pytest` 验证后提交，Git 提交记录可追溯每一步。
- 产品功能侧的 AI（通知结构化提取）输出经 **Pydantic 校验 + 证据回文匹配**，不可核验字段强制置空（前端显示「待核实」）——防止 AI 幻觉进入展示数据。
