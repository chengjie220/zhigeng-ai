## 一句话介绍

把分散在成都大学各网站的竞赛、实践、讲座通知，自动汇总成一份**看得懂、查得快、能追踪**的校园机会清单——每条信息由 AI 提取截止日期、参与对象、报名方式，并附**原文依据**可核验。

## 已实现功能

- **真实采集**：4 个公开信息源（成大官网通知、创新创业学院双创通知/学科竞赛、校团委通知），定时同步、去重、正文清洗；实测单次入库 64 条真实通知。
- **AI 结构化提取**：分类、摘要、参与对象、报名截止（日期+时分）、报名方式、所需材料；每个关键字段附原文证据片段，可在正文中定位高亮；无依据字段一律标「待核实」，不编造。
- **AI 今日简报（首页）**：自动算出「7 天内截止 / 近 7 天新增 / 截止待核实」三个数字，只列 3 条还能行动的机会，卡片上直接给出倒计时、下一步报名方式与参与对象，可一键下钻到完整清单。
- **统一信息看板**：关键词搜索、类别/来源/截止状态筛选、两种排序（最近截止优先/最新发布优先）、分页；筛选状态同步 URL，可分享、可前进后退。
- **详情页**：AI 提取结果 + 原文依据 + 清洗后原文正文 + 附件链接 + 查看原文。
- **收藏与截止提醒**：本地收藏、7 天内截止高亮、已截止沉底、截止待核实标识。
- **工程化**：前后端 94 个自动化测试用例（前端 72 + 后端 22）、响应式（电脑/手机）、完整状态处理（加载/空/错误/解析中）、Mock/真实 API 一键切换。

## 项目起点

赛期内全新项目：11/23 完成前端 v0.1 与接口契约，11/23–24 前端 v0.2（URL 同步、证据定位、测试体系），11/24 完成后端全链路并跑通「真实采集 → AI 解析 → 前端展示」，同日前端 v0.3 把首页从通知列表重构为「AI 今日简报」，先给结论再给清单。仓库 Git 提交记录完整可查（github.com/chengjie220/zhigeng-ai）。未使用旧项目代码。

## 关键依赖

Vue 3 / Vite / TypeScript / Element Plus（前端）；FastAPI / SQLAlchemy / SQLite / HTTPX / BeautifulSoup（后端）；大语言模型 API（OpenAI 兼容，当前可运行规则降级模式）。

## AI 使用方式

1. **产品能力**：LLM 对通知正文做结构化提取（Prompt 版本化，输出经 Pydantic 校验 + 证据回文匹配）；未配置 Key 时规则降级，保证链路可演示可测试。
2. **开发协作**：AI 辅助生成前后端代码、测试用例与文档；全部代码经人工审查、测试验证后入库（详见《AI辅助开发记录》）。

## 已知问题

规则降级的提取质量低于 LLM 模式；收藏/订阅仅存本地浏览器；站点改版需调整采集适配器（已有真实 HTML 夹具测试可回归）；截止提醒为站内展示，无消息推送。
